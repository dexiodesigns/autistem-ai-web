# Autistem — Web

Landing page for **Autistem**, a mobile app that helps caregivers manage the care of an autistic or neurodivergent child — care circle, daily logs, documents, and appointments & medication, all in one calm place.

The page shows a "Coming soon" card while the app is being finished.

## Stack

Static site — no build step.

- `index.html` — markup
- `styles.css` — styles (Newsreader + Inter, "Care Wave" brand mark)
- `logo.jpeg` — brand mark (nav, footer, favicon, coming-soon card)

## Develop

Just open `index.html` in a browser:

```bash
open index.html
```
